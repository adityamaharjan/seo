Critical 5 Pages Affected

Duplicate Title Tags

Multiple pages on your website share the same title tag. This confuses search engines about which page is relevant for a specific query and can lead to lower rankings for both pages.

Difficulty
Easy
lightbulb How to fix: Ensure every page has a unique title tag that accurately describes its content.
Warning 12 Images Affected

Images Missing Alt Text

Search engines cannot "see" images. Alt text provides context for image content, which helps with ranking in image search and improves accessibility for screen readers.

Difficulty
Medium
lightbulb How to fix: Add descriptive alt text to all img tags in your HTML.
